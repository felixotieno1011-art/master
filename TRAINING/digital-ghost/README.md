## The Four-Layer Model (summary)

1. **Address Book** (DNS) — block the name, kill the tracker.
2. **Conversation** (what you send) — HTTPS hides content, not metadata (SNI, UA, IP).
3. **Name Tag** (cookies + fingerprints) — clearing cookies is not enough; randomize.
4. **Shield** (your stack) — defend at every layer: DNS, browser, transport, exit IP.
