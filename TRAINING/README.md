# Mentorship & Training Labs

These labs were built by a senior engineer (my mentor) to train me in cloud engineering and offensive security. I do not claim authorship of the lab code. This folder documents the practical skills I learned by using them.

## MiniAWS (Cloud Engineering)
- **Purpose:** Learn the AWS CLI contract locally.
- **What I did:** Provisioned VPCs, subnets, and parsed JSON outputs using JMESPath (`--query`).
- **Key Takeaway:** Learned how cloud infrastructure is scripted and queried.

## POS Lab (Offensive Security)
- **Purpose:** Practice black-box penetration testing.
- **What I did:** Exploited SQL injection in vulnerable mode, then verified the fixes in secure mode (parameterized queries, JWTs).
- **Key Takeaway:** Learned how to read stack traces, bypass WAFs, and document a vulnerability report.
